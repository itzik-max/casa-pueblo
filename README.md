# CASA | הבית שלי — פורטל לקוחות קאסה פואבלו

אב-טיפוס להצגה, לפי מסמך האפיון גרסה 1.0. כל המסכים עובדים עם נתוני דמו של משפחה אחת (בית אברהמי). אין עדיין שרת או מסד נתונים.

## איך פותחים

- פותחים את `index.html` בדפדפן (לחיצה כפולה). לא צריך התקנה.
- **כניסה כלקוח:** הכפתור "כניסה כלקוח" במסך הכניסה, או `index.html?as=client`
- **כניסה כצוות (Back Office):** הכפתור "כניסה כצוות", או `index.html?as=staff`
- **אזור הלקוח עם תפריט צד** במקום טאבים: `index.html?as=client&nav=side`. אפשר גם לעבור בין התצוגות בכפתור שבהדר.
- השינויים שעושים בהדגמה (אישורים, הוצאות, תמונות) נשמרים בדפדפן.
  - הכפתור "איפוס נתוני ההדגמה" בתפריט מחזיר את הכול להתחלה.

## עיצוב

- **אזור הלקוח:** נייבי עמוק על כל המסך (`css/navy.css`), עם זהב שמפניה וטרקוטה כהדגשה. התפריט בטאבים למעלה, וב-Back Office נשאר העיצוב הבהיר.
- **לוגו:** בינתיים "לוגו טקסט" (Cinzel). הלוגו מהאתר הוא PNG על רקע לבן ולא מתאים לנייבי. צריך לבקש מהם גרסה בהירה או SVG.
- **צבעים:** נייבי `#1e3554` וטרקוטה `#b5562f`, לקוחים מהלוגו.
- **פונטים:** Frank Ruhl Libre לכותרות, Assistant לטקסט.
- **סטטוסים (סעיף 23):** אדום, צהוב, כחול, ירוק ואפור. ליד כל צבע יש תמיד גם טקסט.
- **תמונות:** מהאתר casa-pueblo.co.il. רובן מפרויקט "פינה כפרית ברמת השרון", כולל זוגות אמיתיים של לפני ואחרי. הגודל המקסימלי באתר הוא 775px, ולכן כדאי לבקש מהם קבצי מקור.
- **"על קאסה פואבלו":** הטקסטים בקוביות בדף הבית לקוחים מהאתר (`ABOUT` ב-`js/data.js`).

## השלב הבא: מערכת אמיתית

ההצעה: Supabase (Auth + Postgres + Storage), כמו בשאר הפרויקטים.

- **משתמשים:** טבלאות `profiles` ו-`project_members`, עם תפקיד לכל משתמש בכל פרויקט.
- **הרשאות:** RLS על כל טבלה. כל שורה שייכת ל-`project_id`. לקוח רואה רק פרויקט שהוא חבר בו.
- **טבלאות:** `projects`, `stages`, `plans`, `plan_versions`, `materials`, `expenses`, `payments`, `expense_spaces`, `documents`, `updates`, `photos`, `tasks`, `changes`, `tickets`, `pros`, `notifications`, `audit_log`.
- **שדה פנימי:** `internal` (בוליאני) על מסמכים, הערות ועלויות שלא מוצגים ללקוח.
- **קבצים:** bucket פרטי. כל קובץ נפתח רק דרך signed URL לזמן קצוב.
- **יומן פעילות:** נכתב ע״י triggers במסד, כך שאי אפשר לעקוף אותו מהדפדפן.
- **Phase 2:** OCR/AI לחשבוניות, והתראות במייל, ב-SMS ובוואטסאפ.
